# Ostad_SQA_Final_Project
This project addresses the final assessment requirements for UI and API automation testing. 
The UI scope uses Playwright with JavaScript to test locked-out login behavior, a standard-user shopping journey, and a performance-glitch user's Z-to-A sorting and checkout journey on SauceDemo. 
The API scope uses a Postman collection for login/token handling, user retrieval, PUT and PATCH updates, and negative requests against ReqRes. 
The project includes sequential execution commands, HTML reporting, reproducible documentation.
